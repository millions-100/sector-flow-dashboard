# 섹터 플로우

KOSPI 하락일에 상승한 섹터와 대표 종목을 한눈에 탐색하는 반응형 웹 대시보드입니다.

첫 화면에서 최근 거래일의 상대강도·수급·뉴스를 바탕으로 현재 주도 섹터, 확산 중인 섹터, 다음 후보와 둔화 섹터의 흐름을 보여줍니다.

페이지를 열 때마다 KOSPI와 추적 종목의 최신 공개 시세, 상위 섹터 뉴스를 다시 확인하고 오늘의 관심 섹터·순환 흐름·관심 가격대를 자동으로 계산합니다. 최신 데이터 요청이 실패하면 마지막 검증 데이터가 표시됩니다.

- 하루·1주·2주·전체 기간별 역행 섹터 종합 랭킹
- 시장 대비 초과수익, 상승 지속성, 상승 강도 기반 점수
- 랭킹 섹터 관련 뉴스 요약과 원문 링크
- 종목별 참고 종가, 시가총액, 거래량, 사업 설명
- 현재 주도 섹터 대표 종목의 1차·2차 관심 가격대와 분석 무효화 기준

## 실행

별도 빌드 없이 실행할 수 있습니다. 인터넷 연결이 있어야 최신 데이터가 반영됩니다.

```bash
python3 server.py
```

브라우저에서 `http://localhost:8080`을 엽니다. `dist/index.html`을 직접 열어도 대부분의 기능이 동작합니다.

화면 오른쪽 위의 `↻` 버튼을 누르면 즉시 다시 확인합니다. 공개 데이터 서버의 호출량을 보호하기 위해 일반 재접속은 최대 1분 동안 받은 데이터를 재사용합니다.

## 실제 데이터 연동

`server.py`가 공개 시세·뉴스를 가져오는 계층이고, `dist/data.js`가 화면용 데이터 계층입니다. 데이터 공급자를 교체해도 UI는 그대로 유지됩니다. 데이터 형식은 다음과 같습니다.

```js
{
  date: "2026-09-25",
  kospi: -1.82,
  sectors: [{
    name: "방산",
    returnRate: 3.84,
    stocks: [{ name: "한화에어로스페이스", code: "012450", returnRate: 5.42 }]
  }]
}
```

> 관심도는 상대강도와 종목 확산도를 압축한 관찰 우선순위이며 매수 적합도나 수익 확률이 아닙니다.
> 관심 가격대는 최근 가격에 따른 조건부 관찰 구간입니다. 거래소 체결가와 지연 또는 차이가 있을 수 있으며 투자 판단은 사용자 책임입니다.
